MONKEY BUSINESS FESTIVAL

1. Open this folder in VS Code.
2. In the terminal run: npm install
3. Then run: npm start
4. Open: http://localhost:3000

Important URLs:
- Home: http://localhost:3000/
- Lost & Found: http://localhost:3000/LostAndFound/lost-found.html
- Worker Login: http://localhost:3000/WorkerSystem/worker-login.html

All public website files are inside the public folder so Express can serve them correctly.
